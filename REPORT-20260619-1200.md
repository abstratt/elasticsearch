### Manual fixes beyond the migration data

- **`TestBuildInfoPlugin.java:63`** — `getSystemProperties().putIfAbsent(...)` (a scanner blind spot;
  `getSystemProperties()` is now a `MapProperty` with no `putIfAbsent`). Rewritten to a resolve-and-check
  that preserves the "set the default only if not already configured" semantics. Surfaced by `./gradlew help`.
- **`ElasticsearchJavaModulePathPlugin.java:104-107`** — `setClasspath(files(getClasspath().minus(x)))`
  caused a `StackOverflowError` at execution because `getClasspath()` is now a live
  `ConfigurableFileCollection`, so the collection referenced a derivation of itself. Fixed with the
  internal `DefaultConfigurableFileCollection.replace(current -> current.minus(x))`, which hands the
  transform a snapshot. Surfaced by `./gradlew assemble`.

### Known limitations / issues

- **Two `MapProperty.remove(...)` sites left as-is** (documented in `MIGRATION_NOTES.md`):
  `modules/repository-gcs/build.gradle:301` (`environment.remove(...)`) and
  `qa/restricted-loggers/build.gradle:18` (`systemProperties.remove(...)`). Both `getEnvironment()` and
  `getSystemProperties()` are now `MapProperty`, which has no `remove(key)` and no mechanical lazy
  equivalent. Both live in `Test`-task configuration closures realized only when those specific test
  tasks run — outside the `help`/`assemble` verification path — so they do not affect this migration's
  green build. They will surface if/when those test tasks are configured.
- **Docker distributions not built/verified** (excluded per request).
- **Deprecation handling relaxed.** Many Gradle 9→10 deprecations (Provider API builder-method forms such
  as `WriteProperties.properties(Map)`, implicit parent-project property lookup of `javaToolchains`, etc.)
  remain. Per the migration's "ignore deprecations" guidance these were not rewritten; instead
  `warning.mode=fail` was relaxed so they do not fail the build. Revert both relaxations
  (`gradle.properties`, `verification-metadata.xml`) when migrating against a released Gradle.
